# Sandbox guide — from a fresh workspace to a video

A step-by-step Linux counterpart to a cell-by-cell notebook guide. These are
**terminal commands**, not Colab cells or notebook magics. Run blocks in order,
but choose only the engine and LaTeX profile you actually need.

**AI agents:** read [`AGENTS.md`](../AGENTS.md) first. If the user says only
“LaTeX”, ask whether they want **slim** or **full**. Neither is an implicit default.

## Step 0 — Check the environment

Target: Debian/Ubuntu, Bash, Python 3.11+, Internet access for missing packages,
and root or non-interactive sudo for APT. The verified platform is Debian 13
with Python 3.13.16. Ubuntu and GPU acceleration have not been separately tested.

```bash
cat /etc/os-release
python3 --version
command -v bash apt-get git
id
df -h .
```

If you are not root and system packages need installation:

```bash
sudo -n true
```

Stop if privileges are unavailable; do not pretend the installation succeeded.
Full TeX Live needs several GB and can take substantially longer than the engine.

## Step 1 — Get the scripts into persistent storage

On Arena/E2B, start under `/home/user`. On another provider, use its documented
persistent workspace instead. If Git is missing, install it through your system
package manager first.

```bash
cd /home/user
git clone https://github.com/myabdur212121-afk/manim-sandbox-setup.git
cd manim-sandbox-setup
```

A public clone needs **no token**. If this checkout already exists, reuse it; do
not create a new copy on every run. See Step 9 for updating.

Keep `manimgl.sh`, `manimce.sh`, `latex_slim.sh`, `latex_full.sh` and `font.sh`
together. By default, the directory containing those scripts is also the runtime
workspace. You may inspect the plan without downloading or changing files:

```bash
bash manimgl.sh --dry-run
bash manimce.sh --dry-run
```

> Agent-tool note: `cd` and `export` may not survive separate tool calls. Set the
> working directory each time, or use absolute paths and explicit environment
> variables. A shell command in this guide does not magically activate another
> tool call's environment.

## Step 2 — Choose exactly one engine

### Option A: ManimGL

```bash
bash manimgl.sh
```

Creates `.venv/manimgl` and `bin/manimgl`. The wrapper uses Xvfb when there is no
`DISPLAY`, so the stable OpenGL release can render without a physical screen.
Software rendering is the default in that path; a GPU is not required.

### Option B: Manim Community

```bash
bash manimce.sh
```

Creates `.venv/manimce`, `bin/manim`, and the alias `bin/manimce`. Cairo is the
normal renderer for this setup.

**Both options automatically run `font.sh`. Neither installs the other engine
or LaTeX.** Run both only when explicitly requested. The environments are separate
and can coexist without sharing pip dependencies.

### What the font helper does

First use of a new workspace:

1. Download pinned upstream CMU Serif and Noto Serif Bengali archives over HTTPS.
2. Verify their SHA-256 hashes and extract four CMU faces and nine normal-width
   Noto weights, together with their OFL license files.
3. Save about 5.2 MiB of extracted files under `fonts/`; discard the archives.
4. Register the persistent directory with the current user's Fontconfig.

Later use:

- cache intact + registration present → exit without downloads or cache refresh;
- cache intact + registration missing → register the existing files, no download;
- missing/corrupt family → download that family again, keeping the other one.

The per-user registration is
`${XDG_CONFIG_HOME:-$HOME/.config}/fontconfig/conf.d/50-manim-workspace-fonts.conf`.
No font binaries are distributed in this Git repository.

## Step 3 — Optional LaTeX

Plain text and shapes do not require LaTeX. Skip this step when it was not
requested. Neither command below installs an engine or the shared text fonts.

### Slim: normal Manim math without the full font bundle

```bash
bash latex_slim.sh
```

Includes `latex`, `xelatex`, `dvisvgm`, `standalone`, core/recommended fonts, common
math/science packages and the real `tipa` package. It deliberately omits
`texlive-full` and `texlive-fonts-extra`, but is still a substantial installation.

Supports CE's default `Tex`/`MathTex` and GL's `basic` template. It writes:

```yaml
# configs/manimgl-tex.yml
tex:
  template: basic
```

### Full: the actual complete distro bundle

Run only when full LaTeX was requested:

```bash
bash latex_full.sh
```

Installs `texlive-full`, `dvisvgm` and `tipa`, and selects GL's `default` template.
This supports the extended GL preamble, including `dsfont` and `calligra`.
It is a multi-GB optional install, not a small update.

### Template behavior to remember

- `bin/manimgl` automatically reads the profile generated by the selected
  extension. No scene edits are needed for the included math example.
- If bypassing the wrapper, use `Tex(r"x^2", template="basic")` with slim TeX.
- A user-supplied `--config_file` takes precedence. Its `tex.template` must be
  compatible with the installed packages. A scene that explicitly asks for a
  full template can still require full TeX.
- Full after slim adds packages and switches the profile. Slim after full
  switches the profile but does not uninstall the extra packages.
- Extensions may run before the engine if both use the same `MANIM_WORKSPACE`.

## Step 4 — Verify the selected installation

### ManimGL

```bash
./bin/manimgl --version
.venv/manimgl/bin/python -m pip check
```

### ManimCE

```bash
./bin/manim --version
.venv/manimce/bin/python -m pip check
```

### Shared checks

```bash
bash font.sh --check
ffmpeg -version
fc-match 'CMU Serif'
fc-match 'Noto Serif Bengali'
```

`font.sh --check` is quiet: exit **0** means the saved files are intact and
registered; exit **1** means they need attention. `fc-match` alone is insufficient,
because it can return a fallback font when the requested family is missing.

If LaTeX was selected:

```bash
latex --version
xelatex --version
dvisvgm --version
kpsewhich standalone.cls
kpsewhich tipa.sty
```

The LaTeX installers already compile a test formula to SVG. An actual engine
render is still the final check.

## Step 5 — Render without LaTeX first

Choose the example for the installed engine. These scenes show CMU Serif,
Bengali text, and simple shapes; the GL scene also exercises `GlowDot`.

```bash
# ManimGL
./bin/manimgl examples/check_manimgl.py FontsOnly -w -l -c '#000000' --video_dir videos/gl
```

```bash
# ManimCE
./bin/manim -ql --media_dir videos/ce examples/check_manimce.py FontsOnly
```

Do not add preview/open flags in a headless sandbox. For GL, keep **`-w`** to write
an MP4 instead of opening a window. `-c '#000000'` requests a black background;
GL's own default background is not black.

## Step 6 — Render math, then locate the video

Run only after a LaTeX extension:

```bash
# ManimGL; the wrapper selects the matching TeX profile
./bin/manimgl examples/check_manimgl.py FontsAndMath -w -l -c '#000000' --video_dir videos/gl
```

```bash
# ManimCE
./bin/manim -ql --media_dir videos/ce examples/check_manimce.py FontsAndMath
```

List final outputs, not partial animation clips:

```bash
find videos -type f -name '*.mp4' ! -path '*/partial_movie_files/*'
```

Expected default paths include `videos/gl/FontsAndMath.mp4` and, for the current
CE example/quality, `videos/ce/videos/check_manimce/480p15/FontsAndMath.mp4`.
Check that the file is non-empty before reporting success or offering it to the
user. Render artifacts are ignored by Git.

To use your own scene, replace the example path and class name. GL uses
`from manimlib import *`; CE uses `from manim import *`. They are different APIs.
For Bengali, prefer `Text(..., font="Noto Serif Bengali")`; ordinary pdfLaTeX math
is not a Bengali text pipeline. See `examples/bengali.tex` for a XeLaTeX example.

## Step 7 — Restore after a sandbox reset

On Arena, system package installations and `.venv/` are not saved in workspace
snapshots. Files under the supported workspace can persist, subject to snapshot
limits; `.cache/` and `.local/` are excluded, so they are not the sole font store.

Rerun **the same selected pair**, for example:

```bash
bash manimgl.sh && bash latex_slim.sh
```

The scripts inspect actual package state rather than a stale “installed” marker.
Saved fonts are reused; only their registration may need restoration. Do not
remove `fonts/` or clone into another directory merely because the runtime reset.
Keep large render outputs within your provider's storage/snapshot limits.

## Step 8 — Custom workspace and version settings

The default workspace is the scripts' directory. To separate source code from
runtime data, pass one shared, absolute destination consistently:

```bash
MANIM_WORKSPACE=/home/user/manim-workspace bash manimgl.sh
MANIM_WORKSPACE=/home/user/manim-workspace bash latex_slim.sh
MANIM_WORKSPACE=/home/user/manim-workspace bash font.sh --check

/home/user/manim-workspace/bin/manimgl examples/check_manimgl.py FontsAndMath -w -l -c '#000000' --video_dir /home/user/manim-workspace/videos
```

Use that same location to reuse already-saved fonts. A new, different workspace
starts with a new font cache. Multiple separate workspaces do not automatically
share cached downloads.

| Setting | Default | Notes |
|---|---|---|
| `MANIM_WORKSPACE` | Script directory | Absolute path; same value across every script |
| `PYTHON_BIN` | `python3` | Python 3.11+; used when creating a new venv |
| `MANIMGL_VERSION` | `1.7.2` | PyPI version; other versions are not validated here |
| `MANIMCE_VERSION` | `0.21.0` | PyPI version; other versions are not validated here |
| `LIBGL_ALWAYS_SOFTWARE` | `1` in GL's no-display path | `0` permits hardware use but does not prove it |

GL pins `setuptools==80.9.0` for its `pkg_resources` import and adds `audioop-lts`
on Python 3.13+. Both environments pin `ipython==8.21.0`. Do not remove these
compatibility constraints without reinstalling and testing.

For direct headless GL Python programs:

```bash
LIBGL_ALWAYS_SOFTWARE=1 xvfb-run -a .venv/manimgl/bin/python your_gl_program.py
```

## Step 9 — Update safely

```bash
git status --short
git pull --ff-only
```

Review local modifications before updating. If a sandbox snapshot omitted the
Git configuration and `origin` is missing, restore only the public remote:

```bash
# Only if there is no existing origin:
git remote add origin https://github.com/myabdur212121-afk/manim-sandbox-setup.git
```

Then rerun the chosen installer(s). Never use `git clean -fdx`: it removes ignored
files, including your persistent fonts and local environments. Never put a token
in the remote URL. Installation from this public repository requires no token.
